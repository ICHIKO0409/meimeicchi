# めいめいっち

「めいめいっち」は、iPhoneのホーム画面に追加して遊べるPWA対応のブラウザ育成ゲームです。

## ファイル構成

- `index.html`: ゲーム画面、スタイル、ゲーム処理
- `manifest.json`: PWAの名前、表示方法、アイコン設定
- `service-worker.js`: オフライン用キャッシュ
- `README.md`: 確認方法と公開方法

## ローカルで確認する方法

Service Workerは `file://` では動かないため、ローカルサーバーで開きます。

```bash
python3 -m http.server 8000
```

ブラウザで次のURLを開きます。

```text
http://localhost:8000/
```

一度開いたあと、ブラウザの開発者ツールでオフラインにして再読み込みすると、オフラインでも表示できることを確認できます。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。
2. このフォルダのファイルをリポジトリに追加して、`main` ブランチへ push します。
3. GitHubのリポジトリ画面で `Settings` を開きます。
4. 左メニューの `Pages` を開きます。
5. `Build and deployment` の `Source` を `Deploy from a branch` にします。
6. `Branch` を `main`、フォルダを `/root` にして `Save` します。
7. 数分後に表示されるURLを開くと遊べます。

公開後はGitHub Pages上に置かれるため、Macを起動していなくてもiPhoneから遊べます。

## iPhoneでホーム画面に追加する方法

1. iPhoneのSafariでGitHub PagesのURLを開きます。
2. 共有ボタンを押します。
3. `ホーム画面に追加` を選びます。
4. 名前が `めいめいっち` になっていることを確認して `追加` を押します。
5. ホーム画面のアイコンからアプリのように起動できます。

## 遊び方

- `ごはん`: おなかがふえます。
- `あそぶ`: ごきげんがふえます。少しつかれます。
- `ねる`: げんきがふえます。少しおなかがへります。

ステータスはブラウザの `localStorage` に保存されます。同じ端末と同じブラウザで開くと、前回の続きから遊べます。
