# めいめいっち

「めいめいっち」は、iPhoneのホーム画面に追加して遊べるPWA対応のブラウザ育成ゲームです。

## ファイル構成

- `index.html`: ゲーム画面、スタイル、ゲーム処理
- `manifest.json`: PWAの名前、表示方法、アイコン設定
- `service-worker.js`: オフライン用キャッシュ
- `assets/`: キャラクター画像を置くフォルダ
- `README.md`: 確認方法と公開方法

## ローカルで確認する方法

Service Workerは `file://` では動かないため、ローカルサーバーで開きます。

```bash
python3 -m http.server 8000
```

ブラウザで次のURLを開きます。

```text
http://localhost:8000/
```

一度開いたあと、ブラウザの開発者ツールでオフラインにして再読み込みすると、オフラインでも表示できることを確認できます。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作ります。
2. このフォルダのファイルをリポジトリに追加して、`main` ブランチへ push します。
3. GitHubのリポジトリ画面で `Settings` を開きます。
4. 左メニューの `Pages` を開きます。
5. `Build and deployment` の `Source` を `Deploy from a branch` にします。
6. `Branch` を `main`、フォルダを `/root` にして `Save` します。
7. 数分後に表示されるURLを開くと遊べます。

公開後はGitHub Pages上に置かれるため、Macを起動していなくてもiPhoneから遊べます。

## iPhoneでホーム画面に追加する方法

1. iPhoneのSafariでGitHub PagesのURLを開きます。
2. 共有ボタンを押します。
3. `ホーム画面に追加` を選びます。
4. 名前が `めいめいっち` になっていることを確認して `追加` を押します。
5. ホーム画面のアイコンからアプリのように起動できます。

## 遊び方

- `ごはん`: 食べものを選び、文字をなぞれたら食べられます。
- `あそぶ`: ごきげんがふえます。少しつかれます。
- `ねる`: げんきがふえます。少しおなかがへります。

お世話をすると `careCount` がふえます。成長は4段階です。

- `careCount` が 3: たまごから、あかちゃんになります。
- `careCount` が 10: こどもになります。
- `careCount` が 20: おとなになります。

ステータス、成長段階の `stage`、お世話回数の `careCount` はブラウザの `localStorage` に保存されます。同じ端末と同じブラウザで開くと、前回の続きから遊べます。

## キャラクター画像を使う方法

画像を使いたい場合は、`assets` フォルダに次の名前でPNG画像を置きます。

- `assets/egg.png`: たまご
- `assets/baby.png`: あかちゃん
- `assets/child.png`: こども
- `assets/adult.png`: おとな

画像がない場合は、自動で絵文字が表示されます。

## 文字なぞり

`ごはん` を押すと、食べものを選べます。`おにぎり`、`りんご`、`チョコレート` の文字が1文字ずつ大きく出ます。文字の画ごとに書き順番号が出ます。グレーで表示された文字の線そのものを指でなぞると、めいめいっちが食べます。
